# MuJoCo Kit (experimental)
Reusable MuJoCo boundary, owned by NexusHuman and independent of anatomical models. Existing interfaces are migrated from src/physics. No MuJoCo WASM runtime, model files or validated controller has yet been bundled. Kit schema and runtime API remain unverified against actual Nexus Core/MuJoCo versions. Do not claim physics or V1 is operational.
